# Public operations boundary

This repository contains the public EvolutionNews.net publication output. The
private SciSiteForge operations repository performs source monitoring,
acquisition, evidence preparation, review, and release packaging.

Public artifacts are limited to reviewed briefings and evidence dockets,
claim summaries, source links, verified citation metadata, indexes, feeds, and
correction notices. Source captures, transcripts, prompts, model output,
monitor queries, connector configuration, reviewer notes, and deployment
secrets are not stored here.

The private pipeline exports a validated public bundle. Publication remains an
explicit review and release action; generated public files do not imply that
the underlying source or interpretation is automatically verified.
